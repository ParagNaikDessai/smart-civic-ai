Privacy & Data Security Policy

Understand how coordinates, files, and AI routing logs are processed securely.

1

Location & GPS Coordinates

Our coordinates fetching utilizes the browser standard HTML5 Geolocation API. GPS coordinate gathering is strictly opt-in and requires explicit permission prompts. Coordinate integers pinpoint physical repairs and are never logged for behavioral advertising.

2

Image Evidence Processing

Uploaded image evidence is processed entirely inside browser threads, converting files into standard Base64 data URLs. This sandboxed conversion guarantees that image bytes remain local inside your system memory before secure endpoint dispatch.

3

AI Classification Core

The triaging core parses text inputs strictly for keywords mapping. In cloud-linked modes, text payloads query AI models securely via API gateways. Text structures are not compiled into public model training runs.

4

Simulated Local Storage

By default, local storage variables maintain all simulated case records. This browser sandbox operates locally. Users can wipe simulated tickets instantly by clearing browser cache.

5

Google Sheets & Webhook Routing

When toggled to webhook configurations, tickets write securely to spreadsheet logs. Access to operational spreadsheets is restricted to authorized team leads, protecting coordinate nodes and ticket details.

6

SSL Encryption Standards

Cloud transmissions are forced across standard TLS/SSL connections, preventing snooping along operational routing hops.
